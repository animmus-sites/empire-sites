❓ 60-second guide

  1. Describe it — click 🚀 New Site and just type what you want in the ✨ box. Or pick a venture preset — everything pre-filled.
  2. Edit text — click any text on the page and type. It saves automatically.
  3. Style it — 🎨 Design tab: colors, fonts, site name.
  4. Sections — click a section's edge to select it, then edit / move / delete from the right panel. 🧱 Sections tab adds new ones.
  5. Images — select a section, use the image upload in the right panel.
  6. Go public — 🌐 Publish: download the file, send it to Atlas in chat, say "make it public" — he puts it live and sends back the URL.

⌨️ Shortcuts: Ctrl/Cmd+S save   Ctrl/Cmd+E export
