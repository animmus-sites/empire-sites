Can you actually see what ChatGPT says about me?

Not exactly — and that's the honest part. No tool can read AI engines' private outputs directly. What if my site blocks the scan?

If your robots.txt or site setup blocks access, the audit tells you which checks couldn't run instead of guessing a score — and a blocked robots.txt is itself a fix you'll see ranked. You'll never pay for an audit that couldn't see your site.
